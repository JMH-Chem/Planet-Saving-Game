# 행성 지키기 (Planet Saving Game)

행성이 만들어내는 병력을 드래그로 원하는 만큼 떼어내 움직이고, 적 행성에 **뭉쳐서 돌파할지 / 둘러싸서 수비대부터 깎을지**를
**병력의 위치로** 결정하는 실시간 행성 점령 디펜스 게임. PC(마우스·키보드)와 모바일(터치)을 한 코드베이스로 지원한다.

- 기획 문서: [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md) — 규칙, 전술, 조작, AI, 기술 구조, 로드맵
- 현재 단계: 프로토타입 v0.1 (핵심 루프 플레이 가능)

## 실행

```bash
npm install
npm run dev          # 개발 서버 (같은 Wi-Fi 의 휴대폰에서도 접속 가능: --host)
npm test             # 시뮬레이션 테스트
npm run build        # dist/ 에 정적 빌드
npm run build:single # dist/index.html 한 파일짜리 빌드 (파일 하나로 공유할 때)
```

개발용 URL 파라미터: `?play&ai=2&difficulty=hard&seed=42` 로 메뉴 없이 바로 시작.

## 30초 규칙 요약

1. 행성은 초당 정해진 수만큼 병력을 만든다. 병력은 행성 궤도를 돈다. 궤도가 꽉 차면 생산이 멈춘다.
2. 적 행성 **대기권(점선 원) 안**의 병력은 행성 방어도를 때리고, **밖**의 병력은 사거리 안의 적 병력과 싸운다.
3. 행성 방어막은 궤도 수비대가 유지한다 — 행성 피해 = 공격측 ÷ (공격측 + 수비측).
4. 방어도 0 → 점령. 그 행성을 지키던 적 병력은 **고립**(체력 감소, 공격력 반감)된다.

## 조작

| | PC | 모바일 |
|---|---|---|
| 선택 | 좌드래그 / 아군 행성 클릭 / 더블클릭 | 한 손가락 드래그 / 행성 탭 · 길게 누르기 / 더블탭 |
| 명령 | 우클릭 (행성 위 = 합류·돌파·포위) | 탭 |
| 횡대 | 우클릭 드래그로 선 긋기 | 대형 '산개' 후 탭 |
| 단축키 | A 전체 · Q 절반 · Esc 해제 · F 대형 · G 전체공격 · R 귀환 · Ctrl+숫자 부대 · P 정지 · Tab 배속 · H 전체 보기 | 하단 버튼 |
| 카메라 | 휠 · 가운데 드래그 · 방향키 | 두 손가락 |

## 구조

```
src/sim/     순수 게임 로직 (DOM 없음 · 결정론적 · 헤드리스 테스트 가능)
src/render/  Canvas 렌더러 · 카메라
src/input/   마우스/터치/키보드 → 게임 명령
src/ui/      HUD
src/config.ts  밸런스 수치
```

TypeScript + Vite + Canvas 2D. 외부 런타임 의존성 없음.
